## 三、任务拆分

### P10-T1：后端 Dockerfile 编写

**目标**：容器化后端服务

**文件**：`Dockerfile`（项目根目录）

```dockerfile
FROM python:3.12-slim

WORKDIR /app

# Install dependencies
COPY scripts/etl/requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Copy source
COPY scripts/ scripts/
COPY db/ db/

EXPOSE 8000

CMD ["uvicorn", "scripts.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

**验证**：`docker build -t stock-game-api . && docker run -p 8000:8000 stock-game-api`

---

### P10-T2：前端生产构建

**目标**：构建优化后的前端静态文件

**操作步骤**：

1. 确保 API 地址指向生产域名：
   ```bash
   # frontend/.env.production
   VITE_API_BASE_URL=https://api.stockgame.com
   VITE_WS_BASE_URL=wss://api.stockgame.com
   VITE_SUPABASE_URL=https://oszikuwftdlsnjkheczh.supabase.co
   VITE_SUPABASE_ANON_KEY=<your-anon-key>
   ```

2. 构建：
   ```bash
   cd frontend
   npm run build
   # 输出到 frontend/dist/
   ```

**验证**：`dist/` 目录包含 `index.html` + JS/CSS 资源

---

### P10-T3：云托管部署（后端）

**推荐方案**：Railway（最简单）

**操作步骤**：

1. 去 https://railway.app 注册/登录
2. New Project → Deploy from GitHub repo
3. 选择 `007bba/stock-game` 仓库
4. 配置环境变量：
   ```
   DATABASE_URL=postgresql://postgres:nyWGaq191SUOxMvu@db.oszikuwftdlsnjkheczh.supabase.co:5432/postgres
   SUPABASE_URL=https://oszikuwftdlsnjkheczh.supabase.co
   SUPABASE_JWT_AUDIENCE=authenticated
   SUPABASE_USE_JWKS=true
   PYTHONPATH=/app
   ```
5. Railway 自动构建并部署`r`n6. 容器启动时会先执行 `python scripts/apply_schema.py`，自动把 `db/schema.sql` 应用到目标数据库

**替代方案**：Render / Fly.io / Vercel Serverless

**验证**：Railway 提供的公网 URL 可访问 `/docs`

---

### P10-T4：前端静态部署

**推荐方案**：Cloudflare Pages（免费，全球 CDN）

**操作步骤**：

1. 去 https://pages.cloudflare.com
2. 连接 GitHub 仓库
3. 构建设置：
   - Build command: `cd frontend && npm install && npm run build`
   - Build output: `frontend/dist`
4. 自定义域名：`stockgame.com`（或子域名 `app.stockgame.com`）

**验证**：`https://app.stockgame.com` 可访问

---

### P10-T5：域名解析配置

**操作步骤**：

1. 购买域名（如 `stockgame.com`）
2. DNS 配置：
   ```
   # 后端 API
   api.stockgame.com → CNAME → <railway-url>.up.railway.app

   # 前端
   app.stockgame.com → CNAME → <cloudflare-pages>.pages.dev
   ```

**验证**：`https://api.stockgame.com/docs` 可访问

---

### P10-T6：HTTPS 证书

**Cloudflare**：自动提供免费 SSL
**Railway**：自动提供 HTTPS（`*.up.railway.app`）

如使用自定义域名：
- Cloudflare 自动管理 SSL 证书
- 无需手动配置

---

### P10-T7：CORS 配置更新

**目标**：允许生产域名跨域访问

```python
# scripts/main.py
app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "http://localhost:5173",      # 开发
        "https://app.stockgame.com",  # 生产
        "https://stockgame.com",      # 生产备用
    ],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

## 四、硬约束

1. **DATABASE_URL** 从平台环境变量读取
2. **SUPABASE_JWT_SECRET** 不提交到代码（用 JWKS 方式无需此变量）
3. **HTTPS 必须**启用
4. **CORS 白名单** 仅允许生产域名
