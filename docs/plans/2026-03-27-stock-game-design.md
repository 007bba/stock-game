# 股票训练游戏设计文档（MVP）

- 日期：2026-03-27
- 项目：Stock Game（网页端）
- 目标：构建一个多人联机、训练导向的 A 股仿真交易游戏。核心是“集合竞价判断 + 题材轮动 + 风险控制”。

## 1. 产品定位

- 形态：网页端 MVP（PC 优先）
- 赛制：全服同盘大赛季
- 数据：历史回放（首版不接实时行情）
- 价值：在接近 A 股真实规则的前提下，降低时间门槛并强化训练反馈

## 2. 核心玩法规则

### 2.1 严格 A 股交易规则

- T+1
- 100 股一手
- 涨跌停限制
- 印花税仅卖出收取
- 停牌/复牌生效

### 2.2 撮合规则（统一撮合）

- 周期：每 5 分钟统一撮合一次
- 成交价：最大成交量价
- 同价优先级：时间优先
- 未成交委托：自动延续到下一轮
- 订单类型：仅限价单（MVP）

### 2.3 时间压缩（1 小时 = 1 交易日）

单日 60 分钟结构：
- 开盘集合竞价：3 分钟
- 上午连续竞价：26 分钟
- 午休：2 分钟（不可交易）
- 下午连续竞价：26 分钟
- 收盘集合竞价：3 分钟

补充：
- 周末和法定节假日跳过
- 集合竞价为训练重点
- 训练增强提示（价格偏离/不平衡量）默认隐藏，仅点击 Tips 按钮后显示
### 2.4 集合竞价 Tips 阈值（已定）

- 阈值策略：严格
- 展示规则：仅在极端不平衡时提示（默认隐藏，需用户点击 Tips 按钮）
- 目的：保持接近真实市场噪声环境，避免过度引导

## 3. 赛季与经济系统

- 赛季长度：10 个游戏交易日（约 10 小时真实时间）
- 开赛方式：固定开赛时段（例如每天 20:00-22:00，推进 2 个游戏日）
- 初始资金：100 万游戏币
- 融资融券：禁用（MVP）

### 3.1 交易费用（MVP 简化模型）

- 买入手续费：0.02%
- 卖出手续费：0.02%
- 卖出税费：0.05%（仅卖出收取）
- 说明：首版不严格对齐真实 A 股全量费率口径

## 4. 股票池与数据策略

### 4.1 股票池定义

- 每季 24 只
- 分层：12 龙头 + 8 跟风 + 4 趋势中军
- 来源：围绕某题材/事件窗口（持续一周或更长）的活跃股
- 入池建议条件（满足其二）：
  - 事件窗口内出现涨停
  - 连板 >= 2
  - 成交额分位前 20%
  - 板块内相对强度前列

### 4.2 数据导入机制（离线 ETL）

建议流程：
1. 选事件窗口与候选股票池
2. 导入真实 1 分钟线（raw）
3. 导入交易日历、停复牌、公司行为
4. 统一复权口径
5. 按压缩规则生成赛季可回放数据（compressed）

建议核心表：
- trading_calendar
- raw_minute_bars
- corp_actions
- season_universe
- season_timeline
- compressed_ticks

### 4.3 数据供应商（已定）

- 供应商：Tushare Pro（A 股）
- 首版依赖：历史分钟线 + 日历 + 停复牌 + 公司行为
- 接入方式：离线拉取 -> 本地清洗复权 -> 赛季压缩 -> 只读回放
- 使用范围：仅内部训练使用（不对外商业化运营/分发）
- 风险提示：分钟数据接口有积分门槛，且官方文档标注学习研究用途；若对外运营需单独确认商用与展示/分发授权范围

## 5. 计分与排行榜

- 榜单口径：收益率 + 回撤综合分
- 首版公式：
  - 综合分 = 收益率(%) - 0.5 * 最大回撤(%)

### 5.1 赛季奖励

- 纯荣誉奖励：称号、徽章、排行榜展示
- 不发放可交易或可消耗道具（MVP）

## 6. 系统架构（MVP）

后端建议模块：
- Game API（鉴权、下单、查询）
- Match Engine（5 分钟统一撮合 + 集合竞价）
- Market Replay（按 compressed_ticks 推进）
- Season Scheduler（固定时段推进）
- Ranking Service（计分与榜单）
- Audit Log（订单/撮合/结算审计）

基础设施建议：
- PostgreSQL：账本、订单、成交、赛季数据
- Redis：实时状态与广播缓存
- WebSocket：轮次结果、持仓/资金变化推送

## 7. 联机一致性与反作弊

一致性机制：
- 轮次流程：可下单 -> 冻结 -> 撮合 -> 广播 -> 下一轮
- 每轮生成 tick_id + sequence
- 断线重连按 last_sequence 补发
- 订单使用 client_order_id 幂等去重

反作弊（MVP）：
- 下单/撤单频率限制
- 异常行为检测（异常撤单率、可疑对倒）
- 输入硬校验（涨跌停边界、手数、T+1 可卖数量）

## 8. 非目标（MVP 不做）

- 融资融券
- 期权/期货
- 自建房与战队系统
- 跨赛季资产继承
- 盘中自动新闻生成

## 9. 验收标准

- 可运行：完整跑通 1 个 10 日赛季
- 可公平：全服同一 tick/sequence 结果一致
- 可复盘：任一成交可追溯到订单-轮次-成交-结算
- 稳定性：50-200 人同盘压测通过，关键错误率 < 0.1%

## 10. 开发里程碑（4 周）

- 第 1 周：规则引擎 + 撮合内核
- 第 2 周：ETL 与压缩流水线
- 第 3 周：交易前端 + 联机同步
- 第 4 周：结算榜单 + 审计 + 压测灰度
