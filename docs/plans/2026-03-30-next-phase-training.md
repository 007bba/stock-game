## 二、训练手感核心功能拆解

### 2.1 时间压缩系统（P12）⭐ 重大调整

**目标**：将真实交易日（240分钟）压缩为60分钟游戏时间 = 4倍速

**时间压缩比例**：
- 游戏内1分钟 = 真实4分钟
- 游戏内60分钟 = 真实一天（240分钟）

**时间结构**（游戏内60分钟）：
```
Minute 1-15:   开盘集合竞价 + 早盘（真实 9:30-10:30，每游戏分钟=4真实分钟）
Minute 16-30:  上午连续竞价（真实 10:30-11:30）
Minute 31-32:  午休（不可交易）
Minute 33-58:  下午连续竞价（真实 13:00-14:30）
Minute 59-60:  收盘集合竞价（真实 14:50-15:00）
```

**撮合点**（每5分钟一次 = 12次/天）：
- 开盘竞价：Minute 15（真实9:30-10:00的4分钟数据聚合）
- 上午批次：Minute 20/25/30
- 下午批次：Minute 40/45/50/55
- 收盘竞价：Minute 60

**数据聚合规则**：
- 每5个游戏分钟 = 20个真实分钟
- 每个tick聚合20条原始分钟bar数据
- Quote字段：open=第一个open, close=最后一个close, high=max, low=min, volume=sum

### 2.2 集合竞价训练（P13）

**目标**：训练开盘集合竞价的判断能力

**竞价机制**：
- 开盘前 3 分钟可下单（Minute 1-3）
- 只接受限价单，不可撤单
- Minute 3 统一撮合
- 计算最大成交量价作为开盘价

**训练要点**：
1. **价格预判**：根据昨收 + 隔夜信息，预判开盘价
2. **量能观察**：竞价阶段的买卖盘力量对比
3. **龙头识别**：高开幅度 + 竞价量能判断龙头强度

**任务**：

### 2.4 龙头股买入训练场景（P15）

**目标**：针对性训练龙头股买入时机判断

**训练场景设计**：

#### 场景 1：竞价高开买入
- 条件：龙头股竞价高开 3%+
- 训练点：判断高开强度、竞价量能
- 成功标准：开盘后 10 分钟内涨幅 > 5%
- **多股票对比**：同时观察多只股票竞价涨幅，选择最强龙头 ⭐

#### 场景 2：回调低吸
- 条件：龙头股盘中回调 3-5%
- 训练点：判断回调支撑位、资金承接
- 成功标准：回调后反弹 > 3%
- **多股票对比**：对比龙头股与跟风股回调幅度，判断板块强度 ⭐

#### 场景 3：涨停板买入
- 条件：龙头股封涨停
- 训练点：判断封单强度、开板风险
- 成功标准：封板成功或开板后回封
- **多股票对比**：观察板块内多只股票涨停情况，判断板块效应 ⭐

#### 场景 4：板块轮动识别 ⭐ 新增
- 条件：多只股票同时活跃
- 训练点：识别资金流向，预判下一轮动方向
- 成功标准：提前买入即将启动的股票
- **多股票对比**：必须使用多股票并列展示，观察走势差异

## 五、技术要点

### 5.1 时间推进核心逻辑

```python
class SeasonScheduler:
    def advance_tick(self, season_id: int) -> Tick:
        # 1. 查询当前 tick
        current = self.get_current_tick(season_id)
        
        # 2. 如果是撮合点，执行撮合
        if current.is_matching_point:
            self.match_engine.execute(season_id, current.id)
        
        # 3. 推进到下一 tick
        next_tick = self.get_next_tick(season_id, current.id)
        
        # 4. 广播 tick 事件
        self.broadcast_tick_event(next_tick)
        
        return next_tick
```

### 5.2 WebSocket 事件格式

```json
{
  "event": "tick_advance",
  "data": {
    "tick_id": 123,
    "game_day": 1,
    "minute_of_day": 3,
    "phase": "open_auction",
    "is_matching_point": true,
    "scheduled_at": "2026-03-30T20:03:00Z",
    "next_tick_at": "2026-03-30T20:04:00Z"
  }
}
```

### 5.3 K 线更新逻辑

```typescript
// 前端
wsClient.on('tick_advance', (tick) => {
  // 1. 获取当前 tick 的所有股票 quote
  fetchQuotes(tick.tick_id).then(quotes => {
    // 2. 更新 K 线数据
    quotes.forEach(quote => {
      chart.updateQuote(quote);
    });
    
    // 3. 高亮当前 tick
    chart.highlightTick(tick.minute_of_day);
  });
});
```
